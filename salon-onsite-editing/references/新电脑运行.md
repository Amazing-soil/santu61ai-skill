# 新电脑运行与调用

完整复制本技能目录，包括SKILL.md、agents、references、scripts和assets。将它放入目标Agent实际读取的技能目录，或让Agent直接读取此目录的SKILL.md。不要只复制一个入口文件。

## 安装本技能

在本机克隆三土仓库，完整复制`salon-onsite-editing`到当前Agent实际扫描的目录。例如Codex使用项目`.agents/skills/`或本机已配置的技能根目录；已有同名技能时先备份和比较，不直接覆盖。其他宿主按其实际技能目录，不假定共用Codex路径。

```text
git clone https://github.com/Amazing-soil/santu61ai-skill.git
```

进入`salon-onsite-editing`后执行下文命令。Windows按本机情况用`py -3`，macOS可用`python3`，文中的`python`代表当前可用Python 3.10+解释器。若Agent未发现新技能，重新加载技能或重开对话。

## 只读环境检查

```text
python scripts/doctor.py
python scripts/doctor.py --font-dir <本机字体目录>
```

该程序只查看本机平台、解释器、可执行程序、字体文件和可选ASR包是否存在，不安装、不下载模型、不导入GPU运行时。`ready_for_basic_inspection`只表示Python与FFmpeg/ffprobe的基本入口具备，不代表渲染、美颜、字体、GPU或共享盘已经验收。

| 要做什么 | 需要什么 |
|---|---|
| 技术清单和成片检查 | Python 3.10+、FFmpeg与ffprobe，均可从PATH或显式参数指定 |
| 原声字幕 | 当前电脑可用的转写工具或人工字幕，音频与分句需核听校对 |
| Apple HDR→SDR | macOS、Apple开发工具和本包Objective-C源码；Apple Silicon为本系列已验证路线 |
| GPUPixel美颜 | 本机兼容运行库、资源、编译器与GPU权限；参考颜色文档 |
| 极短混剪 | Node/npm、HyperFrames、GSAP、MiSans Bold/Light，读取实际安装版本的使用指南 |
| 原声/非极短标题 | Ma Shan Zheng与MiSans字体，渲染器需支持正确字形和字重 |
| 共享盘 | 当前电脑实际挂载路径与权限，先做读写回读测试 |

FFmpeg、字体、ASR模型、HyperFrames/GSAP、GPUPixel及GPU驱动不随本包分发。缺项说明清楚，不把GPU包存在当作GPU可用；Metal沙箱报不可用时核对权限和原生arm64环境，不静默更换处理方法。未配好渲染环境仍可先整理、分类和写时间码。

字体从其正式发行方或用户已有合法文件准备，复制到本次工程的fonts目录，保留许可证，不回退到另一种字体而不说明。可参考[MiSans](https://hyperos.mi.com/font/)与[Ma Shan Zheng源码和OFL](https://github.com/google/fonts/tree/main/ofl/mashanzheng)。用户要求携带本地音频时，按[音频素材同步](音频素材同步.md)准备实际文件、索引和来源资料，不能只复制指向原电脑的链接。公开Skill只携带目录与调用方法，音频原文件从已授权的私有素材目录同步。

HyperFrames与GSAP可以使用当前宿主已安装的对应Skill，查不到时先准备运行环境。M01文档提供排版、缓动和时间线标准，不依赖本包以外的旧工程路径；使用暂停、可定位任意时刻的时间线，注册`window.__timelines.main`。别用运行时计时器驱动离线渲染。

## 原片技术清单

```text
python scripts/inspect_media.py --input <原片目录> --output <新批次目录>/原片清单.json
```

逐文件ffprobe和SHA256，保留色彩、旋转、音轨和拍摄时间；输出已存在时停止，避免覆盖。清单中的叙事、清晰度和人物检查均为待判断，不能当作已通过。

## 编译Apple原生导出工具

仅macOS。将下列路径替换为本机实际位置，输出放可写工程目录：

```text
clang -fobjc-arc <技能目录>/scripts/apple_sdr_export.m -framework Foundation -framework AVFoundation -framework CoreMedia -o <工程目录>/apple_sdr_export
python scripts/apple_sdr_cli.py <原片.mov> <新的SDR底片.mp4> --native-bin <工程目录>/apple_sdr_export --start 0 --duration 10
```

程序先原生转换，再只做30fps归一化与音轨复制，生成`.color.json`记录。不接受覆盖输入或既有输出，不额外调亮。先测试短片，输出BT709标签、方向、亮度、首尾与声音仍需实查。

GPUPixel源码与构建方式可参考[官方项目](https://github.com/pixpark/gpupixel)。本包不下载或安装它。现有Mac构建使用CMake，关闭face detector、AAPL framework和shared libs后构建`gpupixel`，再将本包`gpupixel_stream.cc`连接本机生成的`gpupixel`和`yuv`静态库，以及OpenGL、AppKit、QuartzCore、CoreVideo、CoreGraphics、AVFoundation、CoreMedia、Metal框架。具体头文件、库、资源路径由该机器构建产物取得，不照搬原机路径；上游版本不匹配时保留报错，不假称编译通过。

在已准备兼容源码、CMake和Apple编译工具的Mac工作目录，可参考以下实际构建参数。`gpupixel`代表本机源码目录，`gpupixel-build`是新的构建目录；桥接源码已在提交`ef552bf8ce2d0d41fa9b979bfb5c7cf79374ca88`的库上验证，不假定任意上游版本兼容。

```text
cmake -S gpupixel -B gpupixel-build -DGPUPIXEL_ENABLE_FACE_DETECTOR=OFF -DGPUPIXEL_AAPL_FMWK=OFF -DGPUPIXEL_BUILD_SHARED_LIBS=OFF -DGPUPIXEL_INSTALL=OFF -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build gpupixel-build --target gpupixel -j 4
clang++ -std=c++17 -x objective-c++ -fobjc-arc -DGL_SILENCE_DEPRECATION -I gpupixel/include <技能目录>/scripts/gpupixel_stream.cc -L gpupixel-build/out/lib -lgpupixel -lyuv -framework OpenGL -framework AppKit -framework QuartzCore -framework CoreVideo -framework CoreGraphics -framework AVFoundation -framework CoreMedia -framework Metal -o <工程目录>/gpupixel_stream
```

`gpupixel/src`可作为包含`res/`的资源根目录，先确认四张lookup图片实际可读。不能只复制指向另一台电脑或断开共享盘的资源链接。Apple媒体框架或Metal在沙箱中失败时先核对权限，不将权限问题写成硬件不存在。

## 成片技术检查与实际第0帧

```text
python scripts/check_delivery.py <成片.mp4> --report <新检查.json> --first-frame <新第0帧.png>
```

默认核对1080×1920、30fps、BT709、H.264/AAC、有音轨，并完整解码；其他尺寸用`--width`和`--height`。用`--ffmpeg`与`--ffprobe`可指定程序。不自动判断封面内容、声音是否听清、字幕语义或禁用人物，报告会保留这些人工检查项。第0帧实际查看后再与独立封面对照。

## 对Agent说什么

```text
使用 $salon-onsite-editing。
这是我们的现场沙龙，原片目录：……，输出目录：……。
活动日期与场景：……。
人物对应、禁用人物、不外发内容及账号资料：……。
先做环境检查、素材分类和剪辑计划，每类一条样片给我确认。
按完整叙事选中长和短视频，主要讲话听不清的只作混剪备用。
沿用本系列字幕、字体双色、动效、轻美颜和首帧封面。
这次只制作；排期、上传及原片清理不在范围内。
```

只做其中一项时直接说明；批量、排期或归档清理若已授权，按相应范围继续。不在不同电脑自动复用旧上传任务、登录态或共享盘清理记录。
