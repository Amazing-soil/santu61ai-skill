# 曲线变速素材

用于有动作、运镜或明确剪切点的真实素材，例如产品特写、现场 B-roll 和录屏中的非关键过程。来源为[小帅的编导日记的五种曲线示范](https://www.douyin.com/video/7683155537533439278)。下面的倍速与节点是根据曲线形状和使用场景设计的可调起点，原片未提供精确数值。

| 预设 | 速度走向 | 选素材与剪辑落点 |
|---|---|---|
| 闪进 `flash-in` | 1× 后减至 0.55× 并维持 | 两个镜头有相近的动作方向、构图或遮挡物时，将减速用在接入镜头的显露动作上。真正的切点由剪辑工程设置，预览两镜的运动是否接得上。 |
| 跳接 `jump-cut` | 中间短暂冲到 3×，两端 1× | 把速度峰值放在需要掠过的动作上。用预估时间把峰值对齐音乐重拍，跳切由剪辑工程按需完成。 |
| 子弹时间 `bullet-time` | 1× → 0.28× → 1×，中间维持慢速 | 让撞击、落地或表情峰值落在低速段。优先选高帧率素材，低帧率素材在这一段可能出现重复帧。 |
| 蒙太奇 `montage` | 加到 2.5×，下探至 0.45×，再回 1× | 让铺垫快速通过，揭晓或反差出现在低速段。需要两段素材呈现反差时，在剪辑工程安排内容与切点。 |
| 英雄时刻 `hero-moment` | 2.4× 加速起势 → 0.35× 动作定睛 → 2.1× 加速收势 | 适合有起势、峰值、收势的完整动作。先把最清楚的姿态放进慢速区，再检查加速出镜是否自然。 |

## 生成可交付片段

先选包含动作前后余量的源片段，记下关键动作的源时间和目标口播重音或音乐拍点。对白、人脸口型及必须看清的 UI 操作优先保持原速。只需要规划时，在素材表填预设、源时间段、目标拍点和预期时长。

运行 [speed_ramp.py](../scripts/speed_ramp.py)，需要 Python 3、FFmpeg 和 ffprobe。Windows 先按技能说明激活共享环境。输出放到本次任务的本地媒体目录，示例为 PowerShell。

```powershell
python "<技能目录>\scripts\speed_ramp.py" "<源视频>" --preset bullet-time --start 2 --end 6 --fps 30 --plan-only
python "<技能目录>\scripts\speed_ramp.py" "<源视频>" "<媒体目录>\bullet-time.mp4" --preset bullet-time --start 2 --end 6 --fps 30
```

- `--start`、`--end` 使用源视频秒数，`--fps` 设为目标时间线的帧率。输出为无声 H.264 MP4，口播、音乐和音效在剪辑工程对齐。
- 输出 JSON 的 `source_offset` 相对所选源段开头，`output_offset` 相对变速成品开头。确定需对齐的曲线节点后，用「目标拍点时间 − 节点输出时间」得到片段在时间线上的起点。
- 调整速度或节点时，用 `--points "0:1,0.38:1,0.46:0.28,0.57:0.28,0.66:1,1:1"` 代替 `--preset`。每组是源段归一化位置与速度倍数。速度在相邻节点之间连续变化，修改后先查看输出时长，再检查能否放进目标段。
- 脚本按目标帧率采样画面。慢速效果明显掉帧时，优先缩短慢速区、降低减速幅度或换高帧率素材。

交付前预览起点、速度极值、动作峰值及结尾，确认主体清楚，入出点能接上，关键动作和口播或拍点一致。在剪辑交接表写清源范围、预设或自定义节点、成品时长、对齐点及成品路径。需要在剪辑软件里继续改曲线时，一并交付源片段引用与节点数据。
