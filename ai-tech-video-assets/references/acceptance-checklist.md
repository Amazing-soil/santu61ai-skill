# Acceptance Checklist

按交付类型验收：规划表检查内容和可执行性，素材文件还需实际预览。已确认的问题只复查受影响部分。

## Layout

- [ ] 已采用目标工程的实际字幕与 PiP 安全区；独立规划才使用 [右下 PiP 默认方案](visual-rules.md)。
- [ ] 保护区内没有必须阅读的文字或关键图形。
- [ ] 核心大字位于中上区域。
- [ ] 主视觉动势位于中部，不压字幕区。

## Content

- [ ] 每个视觉单元只表达一个核心意思。
- [ ] 文字不超过 1 个主标题 + 1 个副句。
- [ ] 去掉底部说明后仍然成立。
- [ ] 动效服务口播，不只是炫。

## Practical Media

- [ ] 实操录屏/截图段没有被概念图覆盖。
- [ ] 高亮只标关键区域。
- [ ] 不遮挡产品 UI 重点。

## Delivery

- [ ] 素材规划表明确对应口播句子。
- [ ] 标注素材类型和是否需要检索。
- [ ] 标注安全区备注。
- [ ] 给剪辑师的说明可直接执行。

- [ ] 已生成的素材文件可读、已预览；时间为实测或估计已说明，未生成的文件不列为已交付。
