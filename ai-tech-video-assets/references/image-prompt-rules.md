# Image Prompt Rules

用于 GPT Image / AI 图片素材。先读取 [视觉规则](visual-rules.md)，将下列右下 PiP 默认坐标替换为目标工程实际安全区。用户指定风格优先。

## Style

- AI 科技博主口播素材。
- 深色科技背景。
- 简笔画、轻 2.5D、抽象信息图均可。
- 不追求真实摄影。
- 不冒充真实产品 UI。

## Layout

- 核心主体放 `Y=200-1180`。
- `Y=1320-1920` 只留背景氛围。
- 右下 `X=720-1040, Y=1120-1660` 不放核心主体。
- 不在图片里生成字幕、标题、金句条。

## Prompt Must Include

通用安全描述：

> 竖屏 9:16，深色科技背景，核心视觉集中在中上区域，底部留出干净空间给字幕和右下真人画中画。不要在底部放文字、图标、关键物体或结论卡。不要真实摄影，不要真实 UI，不要品牌 Logo。

## Avoid

- 真实办公照片。
- 具体竞品 Logo 或 UI。
- 底部大字。
- 文字塞满画面。
- 右下角主体人物或关键对象。

生成图片优先使用当前可用的内置工具；工程使用前保存到本地媒体目录并查看成图。聊天预览不等于已取得可引用文件。
