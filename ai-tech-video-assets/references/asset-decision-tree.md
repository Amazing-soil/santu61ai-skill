# Asset Decision Tree

## Quick Mapping

| 文案意图 | 优先素材 |
|---|---|
| 差距、增长、趋势、效率鸿沟 | HTML/Anime.js 曲线动效 |
| 判断、结论、观点、标准 | 核心大字冲击动效 |
| 对比、反常识、新旧方式 | 左右对比/切换动效 |
| 任务、流程、执行、交付 | 轨道推进/节点接力 |
| 工作台、Agent、协作 | 任务中心/模块环绕 |
| 混乱、低效、折腾 | 乱线收束/窗口坍缩 |
| 情绪钩子、抽象生活场景 | GPT Image 插画 |
| 真实产品能力证明 | 实操录屏/截图 |

## Practical Segments

实操素材优先级最高。只要用户有真实录屏/截图：

- 不用概念图覆盖。
- 不做复杂 HTML 叠层。
- 只建议局部放大、鼠标/按钮高亮、画中画布局。

## Image Segments

适合 GPT Image 的情况：

- 场景抽象，无法用真实截图表达。
- 需要情绪钩子。
- 需要说明复杂业务但不适合实操。

## HTML Motion Segments

适合 HTML/Anime.js 的情况：

- 需要表现概念、趋势、对比、任务关系。
- 不需要真实 UI。
- 可以用一个核心词和一个视觉动势讲清楚。
