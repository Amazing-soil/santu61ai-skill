# Visual Rules

## First Principle

先采用用户指定或目标工程的画幅、字幕和 PiP 布局。下表仅适用于独立素材的右下 PiP 默认方案；对接其他工程时用其安全区整体替换。核心信息和装饰均应避开人物与字幕。

## Safe Canvas

画幅：`1080x1920`。

| 区域 | 规则 |
|---|---|
| `Y=0-200` | 可放背景氛围，不放核心信息 |
| `Y=200-1180` | 核心大字、主视觉、曲线、对比图、流程图 |
| `Y=1180-1320` | 次级视觉，可选小标签，不能放必须阅读的结论 |
| `Y=1320-1920` | 字幕、人像、平台 UI；素材只能放背景氛围 |
| 右下 `X=720-1040, Y=1120-1660` | 真人 PiP 保护区，素材核心信息不得进入 |

## Typography

- 主标题：宋体/衬线，超大字，1-2 行。
- 副句：最多 1 行或 2 个短行。
- 不做满屏小字。
- 不在底部放 conclusion bar / final card / 金句条。

## Color

- 暗底科技背景。
- 主强调：信号绿 `#1DE58C`。
- 辅助：信号蓝 `#69A8FF`、克制金色 `#F6D365`。
- 避免紫色渐变和花哨霓虹。

## Motion Layout

默认结构：

1. 核心大字
2. 一个视觉动势
3. 可选 1 行副句

底部只保留背景、网格、光斑、粒子，不承载信息。

## Waste Frame

以下情况视为废帧：

- 底部有必须阅读的文字。
- 右下 PiP 区有核心图形或文字。
- 一叠字幕和真人后画面读不清。
- 动效好看但和口播语义无关。
