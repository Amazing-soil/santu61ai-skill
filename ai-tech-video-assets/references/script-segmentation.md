# Script Segmentation

## Goal

按真实语义拆段，每段一个核心意思；`3-5 秒` 作为节奏参考，不强行切断句子。只有文案时标注估计时长，已有音频时用真实时间点。

## Method

对每段口播提取：

- 口播原句
- 核心词
- 观众需要立刻看懂的画面目标
- 素材类型
- 安全区注意

## Segment Types

| 类型 | 判断方式 | 素材倾向 |
|---|---|---|
| 开场钩子 | 引出问题、制造情绪 | GPT Image / 大字冲击 |
| 观点判断 | 给出个人标准、结论 | HTML/Anime.js 核心大字 |
| 趋势差距 | 差距、变化、趋势、鸿沟 | 曲线/轨迹动效 |
| 反常识 | 不是 A，而是 B | 对比切换 |
| 工作流解释 | 输入、执行、交付、协作 | 轨道/节点/任务中心 |
| 产品实操 | 真实软件操作 | 录屏/截图，不加概念图 |
| 总结升华 | 金句、观点收束 | 上半区大字，不做底部金句条 |

## Output Shape

| 段落 | 口播句子 | 核心词 | 视觉目标 | 素材类型 | 备注 |
|---|---|---|---|---|---|
