# 固定模板与检查

## 视觉

通用模板在 `assets/style.json`，排版逻辑在 `scripts/layout.py`。脚本生成的是视频的固定文字和线条版式，不请求每条重新生背景图。默认沿用用户已确认的样式：

| 项目 | 数值 |
|---|---|
| 画布 | 1080×1920，30fps |
| 背景 / 正文 / 重点 | #F4F4EF / #263844 / #2E6B9E |
| 字体 | MiSans Medium，重点 Bold |
| 文字 | 正文 46px，行距 69px，最多 9 行/页 |
| 双窗 | 左 x=50、右 x=546；y=420；各 484×540 |
| 缩放 | 各自 contain，居中完整显示；不裁头、不拉伸 |
| 标题区 | 品牌、每日跟读、主题、天数与素材人物名 |
| 页脚 | 淡色深圳建筑轮廓、“深圳 · 大湾区” |
| 封面 | 第 0 帧完整，静止 0.6 秒；声音和双视频一起后移 |
| 编码 | H.264 CRF18，AAC 192kbps，MP4 faststart |

模板固定但文字不是固定：不得硬编码样片的主题、王志文、第一天或文案到每条产物。标题放不下时保留完整原文，另拟用户可接受的简短展示标题；不能强行压小字体。

## 音画对应

驱动 MP3、右侧视频和合成 WAV 均来自同一处理结果，时间不变。数字人输入复用这段音频，所以默认合成只用 WAV 发声。`attach` 的音频比较在 8kHz 单声道上测量最多 ±3 秒起点差，并检查前中后三段，避免把全片相关性误当成无漂移。

数字人没有声音、改了音色、改变语速或超过 3 秒片头时，低相关性不等于必然错片，也不能直接当正确。核对完整文字和口型；必要时先做对齐副本、记录处理再接收。缺失内容需要补回完整数字人，不能循环人物画面假装对齐。

本技能不把原作者的跟读声认定为影视角色本人的声音；“人物名”只是素材画面标签。无已核实来源时，内部记录保留未核实。

## 验证与修订

机器检查：输出完整解码、1080×1920、声音存在、时长增加 0.6 秒、主音轨与成片声音偏移 0.6 秒、首帧与 0.5 秒画面基本相同。参数及检查数据保存在制作工程。

实际检查：查看第 0 帧、正文开始、中间、末尾和每个换页点；人物没有裁成大头，标题和全文可读，重点逐项对应原画面。试听首句、连接处和末句，检查无截词、重声、明显变调或时间漂移。机器波形检查不能代替自然听感和口型检查。

检查范围、用户已确认的证据和未验证事项分别记录；不为运行 `review` 而虚填已试听。

工程中保留本次用到的脚本、style.json、提取计划与素材记录，修改时复用。脚本拒绝覆盖成片，尤其不经共享盘软链接覆盖已有媒体。需重做时在同一 GD 内容下另建制作目录，调整明确参数并留下来源关联，交付说明只呈现最终有效内容。
