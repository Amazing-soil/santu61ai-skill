# 湾区每日跟读视频制作

一个内容目录完成三段工作：准备素材 → 等待用户制作数字人 → 回传后合成。读取目录里的 `素材记录.json` 继续，不依赖上一轮聊天记忆。支持 GPT-6.1 Sol 等具备文件、终端和画面查看能力的 Agent；模型和推理强度由用户选择，本技能不改会话配置。

## 开始执行

1. 明确本次入口：抖音链接、已下载视频、数字人回传、继续未完成内容。只执行已授权的阶段。
2. 读取当前项目 AGENTS.md、目标账号资料和已有跟读设置。当前品牌为“湾区表达共创社”，默认 XHS-001；不混入其他账号风格。
3. 找到本 SKILL.md 的真实目录，记作 `SKILL_DIR`；已有内容先运行 `status`。输入完整路径，不依赖终端当前目录。
4. [操作命令与目录](references/commands.md)说明各命令和状态；提取前读[提取计划](references/extraction.md)，合成前读[固定模板与检查](references/composition.md)。

## 三个入口

### 准备素材

- 接收链接时调用已安装的 `douyin-copy-extractor`，先实际读取其 SKILL.md。沿用它的单并发、GPU 转写和临时目录规则；不要复制一份下载逻辑。
- 下载前确定本项目的保存目录。调用方已获授权保存原片；在下载技能 `finish` 清理之前，运行本技能 `init` 把原片复制到内容目录，并复制其标准文本结果及转写时间信息。不要向下载技能的三字段结果里塞入项目字段。
- 本地视频直接 `init`，不再下载。有现成已校对文案可复核复用；需要转写时按[本地转写交接](references/extraction.md#本地视频转写)使用已有 GPU 管线。
- 分配 `GD-001` 等稳定编号；原作者 Day81 与自己的“第一天”分别记录。`--library` 是本账号统一的内容集合，去重仅在该集合内生效。
- `frames` 后实际查看开头、中间、结尾以及布局变化处。确定右侧区域，禁止将样片裁剪坐标硬套其他视频。布局随时间变化时分段裁剪再拼接，不能强套一个区域。
- 用语音、画面文字、上下文校对完整文案。原画面红字逐项记录为 `emphasis:true`；跨行红字仍是同一组。不能猜重点或把整句随意标蓝。无法识别的内容标为待核对，仅该条暂停。
- 填好提取计划后 `prepare`，交付带声音的右侧 MP4、驱动 MP3、完整及重点文案、精确重点位置。主音轨 WAV 用于后续合成；用户需要音频 MP4 时加 `--audio-mp4`。
- 默认整体轻微降调 0.5 个半音并补偿语速。已处理过的输入使用 `--audio-already-processed`，不得二次变声。画面裁剪不会分离左右人声，既有混合音轨不能称为已核实影视原声。
- 提取后抽查右侧画面、听音频、核对重点字。状态“等待数字人”时给用户 MP3 路径和编号，本轮结束，不占用进程轮询。

### 数字人回传

- 用户手动生成数字人。本技能当前没有数字人服务连接；以后接入服务，只替换这个交接步骤。
- 先按 GD 编号或用户明确说明匹配，再核对语音、时长和首尾内容。不得仅凭近似时长给多个文件强行配对；不明确的文件保留在待匹配目录并问必要问题。
- `attach` 保留用户原文件并测量声音偏移、三段相关性及残余偏移。结果是匹配线索，不是内容或口型已核验的证明。
- 检查首句、末句、口型、时间起点，确认后用 `align` 记录。已有用户确认可复用，记明证据。缺句、不同内容、语速漂移、无法解释的时间差应修正或补素材，不盲目拉伸、循环或截词。

### 合成成片

- `render` 使用固定模板。左侧保留完整人物，等比例缩小、不裁成大头；右侧对应片段。不拉伸，不通过复杂背景或锐化制造虚假清晰度。
- 使用提取阶段的主音轨一路发声，数字人与右侧原音均不叠加；不再降调，不默认配乐。
- 正常长度全文静态显示；溢出时在同一文字区域按语音时间分页，完整保留文字和重点，不缩小到难读。页与页必须覆盖整段声音，不漏行、不重复行。
- 完整封面停留约 0.6 秒，两个视频和音轨整体同步后移。封面从成片第 0 帧抽取。
- 自动检查后实际看首帧、中间、结尾、换页处并试听。`review` 的标记只对应真实完成的检查；工具能力不足或未试听时如实保留“待成片检查”，不要虚报完成。
- 成片、封面、文案和工程按当前项目规则归档。共享目录迁移用 `archive` 校验后留本地链接；共享盘没挂载时保留本地并说明。详情见[操作命令与目录](references/commands.md#归档)。

## 连续执行与异常

- 多链接按队列逐条完成下载技能全流程并释放锁，再处理下一条。多条制作也按条保存状态；一条缺资料不丢弃已完成结果。
- 相同作品 ID 或文件指纹不重复导入。重复调用先看状态，复用已完成阶段。已归档文件不能经软链接被静默覆盖。
- 脚本会拒绝已有输出。失败临时目录自动清理；若文件已生成但状态写入前中断，核对实际文件后恢复记录，不重复变声。修订保留原产物，在独立制作目录完成后关联同一 GD 编号。
- 不伪造影片名、集数、主持人出处，不把来源博主的标题当成核实结果，不移除素材原有生成标识。
- 交付说明保持自包含，说明实际产物与未验证项。不上传用户视频、数字人、音频、转写内容到技能仓库；仓库仅保存技能代码、通用模板与说明。不自动排期或发布。
