# 画面与素材规划

先读整段口述，再决定观众此时需要看人还是看内容。镜头按语义分段，短句可延续当前画面，不机械一句一卡或每几秒换素材。

| 画面模式 | 适合内容 | 真人 |
|---|---|---|
| `host` 真人讲述 | 判断、经验、情绪表达、开场与结尾 | 为主；竖版开头结尾用居中缩放卡，不用全屏人物，重点大字放卡片上方和字幕下方 |
| `split` 真人配图 | 边讲边解释产品、截图、指令、关系或简单流程（正文默认） | 小窗居中在字幕下方，尺寸要小，内容区为主 |
| `chapter` 全屏章节 | 明确的阶段、步骤、话题转换 | 完全隐藏，原声继续 |
| `content` 全屏内容 | 确需整屏的录屏、复杂图示 | 隐藏；一般正文优先用 `split` 带小窗，避免画面空 |

章节页可由大编号、主标题与必要的小标签构成，一页表达一个章节。参考少色、字号层级、留白和信息对齐方法，自行实现；不将某套模板的纸色、字体、套印、颗粒或明暗交替设为通用要求。统一主题，真实产品图标保留正确颜色。黑底是可选主题配置，用户指定全黑时章节页也保持全黑。

章节时长从实际口述和可读性决定，约 2—4 秒只是起点。入场、停留、退场容纳不下时减少文字和动作，不插入额外时长、不暂停或重排原口播。章节后可回真人，也可延续全屏解释。实现见 [组件说明](composition-components.md)。

| 口播内容 | 优先素材 |
|---|---|
| 产品操作、网页流程、能力证明 | 真实录屏或截图，局部强调，不覆盖关键 UI |
| 对比、分层、流程、判断标准 | 原创图示或适合的 TalkCraft 组件 |
| 抽象隐喻、商业场景、未来推演 | 有表达价值的 GPT Image 插画或已有图片 |
| 短过渡句 | 延续相邻画面、章节页或真人 |

不设置 AI 图片频率、素材比例或动效数量。图片、录屏、动效和真人各自服务内容；没有必要时不额外生成图片。图片按实际全屏或分屏区域构图，不一律生成 9:16；避开当前字幕及真人区域。图片不生成字幕、Logo、假产品 UI；生成画面只能作示意，不冒充真实案例。

素材放入工程本地媒体目录，保存来源与实际路径。色彩、字体和留白由同一主题配置控制；真人隐藏后内容重新居中或铺开，不保留空人像框。横竖版分别安排版面，不能简单给竖版加左右黑边。
