# 素材规划

以真实口播语义选择素材，每段表达一个核心意思。

| 口播内容 | 优先素材 |
|---|---|
| 产品操作、网页流程、能力证明 | 真实录屏或截图，局部高亮，不覆盖关键 UI |
| 对比、分层、流程、判断标准 | React/Remotion/Anime.js 动效或信息结构 |
| 抽象隐喻、情绪钩子、商业场景、人物群像 | GPT Image / AI 图片 |
| 短过渡句 | 延续相邻素材、轻背景或不加素材 |

## 默认混合节奏

通常混合 AI 图片与动效，避免整片文字信息图或图片幻灯片。无实操录屏的常规成片，至少安排一个图片段和一个动效段；每个完整 30 秒窗口默认安排至少一张、宜一至两张 AI 图片。全实操窗口、用户指定截图风格、过短视频或生图不可用时，按表达需要调整，并简要说明实际采用的方案，不为凑数量生成无关画面。

每 3–5 秒检查是否需要视觉变化，按语义与可读时间决定切换。3 秒以内的句子通常并入相邻素材；播不完的动效简化、变速或换静态图。

## 图片与色彩

- 默认 9:16，主体在中上区域，避开本工程的字幕与 PIP 保护区。
- 图片不生成标题、字幕、金句、Logo、假 UI 或播放按钮；真实产品能力用真实截图展示。
- 无品牌要求时使用深炭黑、冷白，琥珀金或冷蓝作主强调；绿色只作局部信号色。完整色彩参数见 [工程规则](remotion-rules.md#color-system)。
- 保存到 `public/media/images/` 或等价媒体目录，时间线引用如 `media/images/scene-01.png`。确认文件可读，渲染后确认没有空白或路径丢失。
