# TalkCraft 接入说明

## 职责与调用时机

主技能使用已剪好的口播组织整片。TalkCraft 提供重点段落的分镜方法、动效组件、转场及配套音效，输出并入同一个主工程。

开场钩子、层级递进、数字变化、原片对照、复杂概念和结尾观点可考虑调用；以帮助理解和突出表达为依据，不将这些位置全部设为必做动效。真人自然讲述可以独立承担段落，不为静止检测机械增加运动。

## 按需读取与复用

从当前环境实际安装的 `video-talkcraft` 目录读取入口并定位相关资源，不假定其他机器使用同一绝对路径。按任务读取：

| 需要 | TalkCraft 内的资源 |
|---|---|
| 重点段落分镜 | `references/shot-design.md`、必要时 `references/cinematography.md` |
| 选择动效卡 | `references/taxonomy.md` → 选中卡的 `references/cards/` 与 `template/cards/` |
| 转场 | `template/motion-systems/transitions.tsx` |
| 配套音效 | `demos/_lib/sfx-map.js`、`demos/_lib/sfx/ATTRIBUTION.md` |

仅复制实际使用的组件和必要依赖到本片工程，保留适用的许可与来源信息。先核对组件输入、时序、素材路径及运行依赖，再适配当前工程；不能只写卡片名称而没有实现。

## 每段输入与输出

输入包括：原句、起止时间、画面目的、可用素材路径、真人位置、字幕安全区、画幅和当前视觉风格。字幕和动作锚点以剪后真实口播为准，不按文案长度估算成已校准时间。

输出记录在本片分镜资料和实际配置中：

| 字段 | 内容 |
|---|---|
| 段落 | 稳定 ID、原句、起止时间 |
| 画面 | 要解释或突出什么；背景、主体和文字如何安排 |
| 素材 | 实际本地路径；区分真实素材与生成示意图 |
| 人物与字幕 | 位置、尺寸、保护区域和状态切换 |
| 动效 | 组件、参数、入场与退场时间、触发词 |
| 音效（如有） | 本地文件、时间点、音量与来源 |

使用主工程已有数据结构，不因接入而强制维护第二套时间线。缺少素材时优先补真实截图或图片，适合示意的内容可使用 GPT Image；生成内容不得冒充实测效果。

## 规则适配

- 用户要求优先。整片画幅、真人布局、字幕安全区、制作节奏和交付由主技能统一；不自动套用 TalkCraft 的横屏默认、人物角标常驻或逐镜确认流程。
- 用户已授权完成整片时持续制作；用户要求先看分镜、样片或逐镜确认时，按其约定等待。
- 复用卡片保留关键运动逻辑、时序关系和技术约束，字体、颜色、尺寸及位置适配当前片子。时长不合适时调整或简化设计，不强塞动作。
- 默认按需字幕，不因为使用 TalkCraft 就额外烧录字幕。真人、字幕、素材过渡期间也要互不遮挡。
- 原口播音频只播放一次，B-roll 默认静音；音效服务于表达，不强制配置或追求数量。
- 本接入方式不包含 Workbench 数据适配。Remotion Studio 是开发预览入口；未验证编辑与导出能力前，不将其称为可直接改字的平台，也不宣称工程已经支持 TalkCraft Workbench。

## 故障与告知

分镜参考和动效卡是本地文件，不依赖在线网站提供核心能力；渲染需要本地运行环境，外部素材采集等功能可能需要网络或服务配置。

调用遇到文件缺失、组件依赖或运行错误时，及时说明受阻能力、具体原因和受影响镜头。对可修复的问题先在当前任务范围内尝试修复，并告知结果。若仍需改用其他实现，提出具体替代方案并等待用户确认，不静默跳过。等待期间可继续不依赖该问题的制作工作。

## 检查与交付

先抽查重点段落与真人布局切换的画面，确认文字可读、素材正常、人物无遮挡和动作时间正确。需要判断运动或音画关系时渲染对应片段，静帧不能替代时域检查。

按主技能的验收规则检查最终 MP4：画面、字幕、音画同步、音效与人声关系、帧数及编码参数。使用 TalkCraft 检查脚本时先核对输入格式和适用范围，不为满足不适用的阈值扭曲真人口播。明确实际检查结果与未覆盖部分。
