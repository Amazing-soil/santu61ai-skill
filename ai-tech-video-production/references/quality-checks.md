# 成片验收

只执行与本次交付有关的项目。通过后交付；发现问题只修复并复查受影响部分。规划任务不要求渲染成片。

## 画面与声音

- 核心信息、字幕和真人互不遮挡；按 [实际 PIP 保护区](remotion-rules.md#asset-layout-safe-area) 检查正文与居中阶段，人物无拉伸，实操 UI 清晰。
- 素材与真实口播关键词对齐，特别检查开头、数字、结论、转折与 CTA；关键入点默认不晚于核心词后 0.3 秒。
- 混合素材服务语义，符合 [素材规划](asset-planning.md) 的默认节奏或有合理调整；色彩、字号、短标签和顶部留白符合所选视觉方案。
- 片头、片尾的 PIP 移动平滑，背景内容成立；素材过渡和桥接没有闪屏、黑帧、路径缺失或底图意外露出。
- 原口播声音完整、清晰且不重复播放；字幕如有，文字和时间以真实音频为准，断句自然、可读，且可编辑数据已保留。
- 新闻、产品能力和数字有依据，概念素材未冒充实测截图。

## 文件与交付

用实际成片路径运行：

```bash
ffprobe -v error -show_entries format=duration,size,bit_rate:stream=index,codec_type,codec_name,width,height,avg_frame_rate,duration,bit_rate -of json final_hq.mp4
```

核对用户要求或 Skill 默认的尺寸、帧率、时长、编码、视频码率和 AAC 音轨。某字段缺失应继续检查，不能当作零值或已通过。检查最终文件的关键帧，并播放开头、重要转场和结尾的代表片段；无法播放或听音时说明验收限制。

确认 `final/` 成片、`images/` 图片和 `previews/` 验收图可读；字幕任务保留 `subtitles/`，工程交接任务保留工程及媒体依赖。低码率预览不替代最终成片。

只在所有必要交付物保留并回读后，按 [运行环境与清理策略](runtime-cleanup-policy.md) 处理本任务临时文件。交付写清文件路径、实际规格、立即清理结果、修改缓冲期截止时间和未满足的要求。
