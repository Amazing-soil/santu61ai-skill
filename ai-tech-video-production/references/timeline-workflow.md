# 真实口播时间线

## 输入与对齐

检查视频时长与音轨，用 ASR、现有字幕时间戳或人工听音定位口播。文案仅帮助理解语义和纠正明显错听，不反向覆盖真实表达。只有文案时可给估计方案，不能生成声称已校准的成片时间线。

对开头钩子、数字、结论、转折和 CTA 核对实际音频时间点。素材入场贴近对应关键词、停顿或手势，原则上不晚于核心词后 0.3 秒；发现漂移先修正时间线。标记开头和结尾的真实句子边界，居中 PIP 默认各约 3 秒，短句按实际边界缩短，避免两段重叠。

## 段落数据

每段记录 `id`、`start`、`end`、`kind`、`asset`、`assetDuration`、`note`、`enabled`；`kind` 使用 `video / image / none`。需要制作素材时在 `note` 写明原句、核心意思和入场触发词。时间必须落在视频范围内，开始早于结束，转场重叠应有明确用途。

按语义决定切换，不机械每隔几秒换图。动效按段落长度计算播放速度，短到看不懂时简化或换静态画面；连续素材可桥接小空档。素材选择与默认密度见 [素材规划](asset-planning.md)。

## 按需字幕

用户要求字幕时生成独立可编辑字幕轨，文字和起止时间以真实口述为准；明显错听或无意义语气词可轻微整理，不改变观点和数字。

按自然语义、停顿和转折断句。逗号连接两层意思时拆条，短并列词可保留；不要把所有逗号机械当作切点。显示尽量单行，长句可在可读范围内缩小字号，仍过长则按语义拆条，最后考虑两行。布局与字体见 [工程规则](remotion-rules.md#subtitle-track)。

## 交接

按需使用 [时间线表](../templates/timeline-table.md) 和 [剪辑师说明](../templates/editor-handoff.md)。标明每句对应素材、入场时间、显示区域、变速、PIP 阶段和字幕来源；无法确认的时间点明确标注。
