# 抖音收藏变成本地知识库

把自己收藏的抖音视频，整理成可搜索、可编辑的 Markdown：保留完整发布文案和经校对的口播，按“自媒体对标”或“知识收藏”分类。同一作品只存一份，失败条目可以继续处理，分类可以随时调整。

**只安装这个技能即可。** 收藏流程需要的提取运行时已随包提供，不必安装仓库里的其他视频制作技能。浏览器、Python、FFmpeg 和 GPU 转写依赖仍需在本机准备。

## 第一次对 Agent 说什么

安装、重开对话后，将下面这段发给 Codex 或 WorkBuddy：

```text
使用 douyin-favorites-kb 整理我的抖音收藏。
先读取这个技能的 INSTALL.md 和 TERMS.md，定位实际安装目录，检查 Python、FFmpeg、Ego 浏览器和 GPU。
把检查通过的 Python 绝对路径告诉我，后续都用这个解释器执行。
知识库放在：<填写本机完整目录路径>
我的抖音主页：<填写本人主页链接>
先确认登录的是我自己的账号，只整理 3 条视频，保留完整发布文案和口播，然后分类入库。
每条完成后清理临时媒体。样本做完等我确认，不启动定时任务。
```

Codex 也可用 `$douyin-favorites-kb` 点名。WorkBuddy 在“已安装”中确认启用后，用技能名调用；不要把 `$` 或 Codex 专有工具当成必需条件。

使用前要有：本机目录读写、运行命令、浏览器连接和联网权限。登录与验证码由你亲自处理；不需要把 Cookie、密码或 API key 发给技能作者。

## 保存的内容

```text
抖音收藏知识库/
├── 分类规则.md
├── 索引.md
├── 01-自媒体对标/选题与角度/作品ID-短标题.md
├── 02-知识收藏/AI工具与应用/作品ID-短标题.md
├── 99-待分类/
├── .同步状态.json
└── .同步锁
```

每条正文包含来源链接、作者、时长、两段全文和基于内容的理解。摘要不能代替全文；听不清的地方保留标记。视频、音频、截图和转写中间文件只用于当次处理，完成后清理。模型缓存保留供后续复用。

## 后续怎么用

| 需求 | 可以直接说 |
|---|---|
| 继续整理 | “继续整理收藏，按现有规则处理未入库视频，本次最多 10 条。” |
| 增加分类 | “新增‘知识收藏/产品设计’，先修改分类规则，再用于后续内容。” |
| 调整旧条目 | “把作品 ID 为……的条目移到……，保留两段全文，不重新下载。” |
| 补提失败条目 | “检查失败原因，解决后恢复这些作品的重试。” |
| 查看进度 | “告诉我已入库、待处理的数量，以及上次是否完整扫描。” |
| 定时运行 | “先验证本机能完成一条提取，再帮我配置每天……执行，时区为……。” |

首次默认 3 条供确认；日常默认每次处理 10 条。完整扫描与处理完全部积压是两件事，会分别报告。技能文件本身不会自动定时运行。

暂不处理图集或直播；登录失效、作品下架、GPU 不可用或文字无法完整确认时会记录原因。只支持本人账号当前可访问的收藏，不提供绕过登录、验证码或访问限制的功能。
