## 数据会去哪里

| 数据 | 处理位置与用途 |
|---|---|
| 登录状态 | 由本机 Ego 浏览器管理，不随技能包分发 |
| 作者、作品链接、发布文案、转写文字 | 交给你当前使用的 Agent 做校对和分类；使用云端模型时可能随上下文发送给该服务商，适用该服务商的数据政策 |
| 视频、音频、截图、原始转写 | 保存在提取器创建的本机临时目录，成功或正常失败时清理；异常退出需执行恢复清理 |
| 分类规则、完整正文、索引、失败状态 | 保存在你指定的知识库目录；若该目录启用云同步，文件也会按你的同步设置上传 |
| Whisper 模型权重 | 首次从模型托管站下载并缓存在本机，用于本地 GPU 转写 |

技能脚本不设作者的数据接收服务，不内置遥测或向作者回传收藏。**本地保存不等于所有数据都只在本机处理**：Agent 的模型服务、Ego 浏览器、平台及你的云同步工具按各自政策工作。不要把私人收藏、Cookie、含签名的媒体 URL 或完整日志提交到公开 GitHub Issue。
