# 提取结果格式

`record.json` 只允许以下结构：

```json
{
  "basic_info": {
    "platform": "抖音",
    "author": "作者昵称",
    "duration": "04:06",
    "work_id": "7546212425998454074",
    "source_url": "https://www.douyin.com/video/7546212425998454074"
  },
  "publish_copy": "发布正文，保留话题标签",
  "corrected_transcript": "经校对、分段后的完整口播文案"
}
```

## 字段要求

- `basic_info`：只保留平台、作者、时长、作品 ID 和标准作品 URL。
- `publish_copy`：只保留创作者发布的正文和话题标签，删除分享口令、复制提示及短链周围的噪声字符。
- `corrected_transcript`：完整保留视频实际表达，只做听写校正、断句和分段，不进行二次改写。
- 不允许出现媒体 URL、下载地址、本地临时路径、ASR 引擎、模型、置信度、截图、字幕文件名、浏览器状态或 Cookie。

## 人类可读格式

需要在回复或文档中展示时，可以转换为：

```markdown
## 基本信息

- 平台：抖音
- 作者：作者昵称
- 时长：04:06
- 作品 ID：7546212425998454074
- 来源：https://www.douyin.com/video/7546212425998454074

## 发布文案

发布正文，保留话题标签

## 口播文案校正版

经校对、分段后的完整口播文案
```

本技能只生成或返回提取结果，不附加项目分类、标签、分析、索引或入库字段。
